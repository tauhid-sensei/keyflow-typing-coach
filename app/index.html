QUICK SETUP

Pin KeyFlow for quick access

Your browser does not let extensions pin themselves automatically. Pin KeyFlow once and it will stay in your toolbar.

  1. Click the Extensions puzzle icon near the browser address bar.
  2. Find KeyFlow Typing Coach.
  3. Click the pin icon next to it.

Chrome, Edge and Brave: use the puzzle icon. Firefox: open the extensions menu and choose “Pin to Toolbar” if available.

Settings

Your key is saved in this browser extension's local storage and sent to the configured provider only when you request AI advice. API usage may cost money. Browser based API calls may be blocked by some providers' CORS policies. Do not use a shared PC profile. For stronger key protection, use a local backend.
